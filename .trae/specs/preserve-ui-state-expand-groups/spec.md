# 保持页面状态并新增展开全部 Spec

## Why
当前在删除等操作后会触发整页重载或等效的全量状态重建，导致分组展开状态和选中状态丢失，影响连续操作体验。用户还需要对疑似重复和确定重复分组提供“展开全部”能力以提升批量核查效率。

## What Changes
- 修复删除及其他数据操作后的状态丢失问题，确保页面状态在非主动刷新场景下持续保留。
- 增加“疑似重复分组”和“确定重复分组”的“展开全部”按钮，并支持一键展开当前列表。
- 排查并修复同类会导致状态丢失的交互路径（如批量删除、排除、保留此文件后刷新数据）。

## Impact
- Affected specs: 重复分组交互、页面状态管理
- Affected code: `movie_manager/templates/report.html`, `movie_report.html`, 相关前端状态与数据刷新逻辑

## ADDED Requirements
### Requirement: 分组一键展开
系统 SHALL 在疑似重复和确定重复两个分组区域提供“展开全部”操作。

#### Scenario: 疑似重复展开全部
- **WHEN** 用户点击疑似重复区域的“展开全部”
- **THEN** 当前疑似重复列表中的所有分组行均处于展开状态

#### Scenario: 确定重复展开全部
- **WHEN** 用户点击确定重复区域的“展开全部”
- **THEN** 当前确定重复列表中的所有分组行均处于展开状态

## MODIFIED Requirements
### Requirement: 页面状态持续性
系统在用户执行删除、批量删除、排除、保留此文件等数据变更操作后，不应通过整页重载导致前端临时状态丢失。应在数据更新后尽可能恢复并保留以下状态：已展开分组、各组勾选状态、跨组勾选统计状态。

#### Scenario: 删除后保持状态
- **WHEN** 用户在已展开且已勾选多个分组项的情况下执行删除操作
- **THEN** 页面不发生整页重载，且可保留/恢复已有展开与勾选上下文（仅移除被删除项）

#### Scenario: 其他操作后保持状态
- **WHEN** 用户执行排除、保留此文件或批量删除等操作
- **THEN** 页面状态不因全量重建而丢失，用户可继续在原上下文中操作
